# calculateavggrade
A simple python script that makes it super easy to calculate your average grade based on a list of grades using the Danish 12 point grading scale and a list of ECTS points for each course.

# How to run?
Navigate to folder where script is saved, and run the following command.
```
python main.py [list-of-grades] [list-of-ects]
```

## Example parameters
```
python main.py [4,7,12,4,10] [5,5,10,5,10]
```

> [!NOTE]
> Ensure that the two lists are of equal length.
